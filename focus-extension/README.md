# Focus — Horizon Chrome Extension

Chrome extension companion for Focus — Horizon.

## Local setup

The extension reuses the Supabase environment variables from `../focus-app` through Vite's `envDir` configuration:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

From `focus-extension/`:

```bash
npm install
npm test
npm run typecheck
npm run build
```

Then open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select `focus-extension/dist`.

## Google OAuth callback

Google sign-in uses `chrome.identity.launchWebAuthFlow()` and the callback generated by:

```ts
chrome.identity.getRedirectURL('auth')
```

For local development, add this pattern to Supabase **Authentication → URL Configuration → Redirect URLs**:

```text
https://*.chromiumapp.org/**
```

For the published Chrome Web Store build, replace the broad development pattern with the exact extension callback shown by `chrome.identity.getRedirectURL('auth')`, for example:

```text
https://<extension-id>.chromiumapp.org/auth
```

The extension uses the same Google provider and Supabase project as Focus Web.

## Current 1.0 scope

- Persistent focus timer
- Start, pause and reset
- Timer completion notification
- Water reminders at 30, 45, 60 or 90 minutes
- Local timer/reminders without authentication
- Google sign in with the existing Focus account
- Load active Focus tasks and projects
- Associate a Focus task/project with the extension timer

Side Panel is intentionally deferred until after the popup workflow is stable.
